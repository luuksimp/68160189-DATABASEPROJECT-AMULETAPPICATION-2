# ตลาดพระเครื่อง (PHP + MySQL)

หน้าตาอิงเทมเพลต "ตลาดพระเครื่อง" (โทนเขียว-ทอง) ใช้ฐานข้อมูลและฟีเจอร์เดิมทั้งหมด + หน้าใหม่ + ปรับให้เสถียรขึ้น

## ติดตั้งใหม่
1. XAMPP / Laragon (PHP 8.1+ และ MySQL/MariaDB)
2. คัดลอกโฟลเดอร์ไปไว้ที่ `htdocs/amulet-market`
3. phpMyAdmin → Import `database.sql`
4. คัดลอก `config.example.php` เป็น `config.php` แล้วแก้ user/password (`config.php` ไม่ถูกเก็บใน Git)
5. เปิด `http://localhost/amulet-market/`
6. (ไม่บังคับ) ใส่ข้อมูลตัวอย่าง 4 รายการจากเทมเพลต: `php tools/seed_demo.php`

## อัปเกรดจากเวอร์ชันเดิม (มีข้อมูลอยู่แล้ว)
1. **สำรองฐานข้อมูลก่อน**
2. Import `migration.sql` ใน phpMyAdmin (รันครั้งเดียว) — เพิ่มสถานะใหม่ ที่อยู่จัดส่ง ตารางรายการโปรด/กันเดารหัส และหมวด "พระกรุ"
3. เปิด `config.php` เพิ่มค่าจาก `config.example.php` ส่วน "ค่าเพื่อความเสถียร" (ถ้าไม่เพิ่ม ระบบใช้ค่าเริ่มต้นให้)

## ที่ปรับให้เสถียรขึ้น
- **ไม่โชว์ error/รหัสฐานข้อมูลบนเว็บ**: error ทั้งหมดลง log แล้วแสดงหน้าแจ้งที่เป็นมิตร (`APP_DEBUG=true` เฉพาะตอนพัฒนา); ต่อ DB ไม่ได้แสดงหน้า 503 ไม่ใช่ stack trace
- **Transaction ทุกขั้นตอนสำคัญ** (สั่งซื้อ, ชำระ, จัดส่ง, รับของ, ยกเลิก, รีวิว) ล็อกแถวด้วย `FOR UPDATE` แล้วเช็คสถานะซ้ำ และลองใหม่อัตโนมัติเมื่อชน deadlock — กดซ้ำ/สองคนกดพร้อมกันก็ไม่ซ้ำ ไม่ค้างครึ่งทาง
- **คำสั่งซื้อที่ไม่ชำระ** ถูกยกเลิกและปล่อยพระกลับมาขายอัตโนมัติหลัง `ORDER_HOLD_HOURS` (เดิมพระค้าง "จองแล้ว" ตลอดกาล); ยกเลิกแล้ว **เก็บประวัติ** แทนการลบแถว
- **UNIQUE + UPSERT**: รีวิวซ้ำ, สมัครซ้ำ, กดไลก์/โหวตรัว ไม่ทำให้เกิดหน้า error
- **กันเดารหัสผ่าน**: ผิด 5 ครั้งใน 15 นาที (ต่อชื่อผู้ใช้+IP) ต้องรอ
- **อัปโหลดรูป**: ตรวจชนิดจริง/ขนาดพิกเซล/ขนาดไฟล์, ลบไฟล์ทิ้งอัตโนมัติถ้าบันทึกฐานข้อมูลไม่สำเร็จ (ไม่เหลือไฟล์ขยะ)
- **เวลา**: PHP กับ MySQL ใช้ timezone เดียวกัน (Asia/Bangkok) "x ชั่วโมงที่แล้ว" ไม่เพี้ยน
- ปุ่มกันกดซ้ำ, จำกัดความยาวข้อมูลทุกช่อง, query ฟีดไม่ยิง DB ซ้ำรายโพสต์, ตลาดแบ่งหน้า
- `.htaccess` ซ่อน `config.php` / `*.sql` / `.git`, ใส่ security headers พื้นฐาน

## หมายเหตุ / ข้อจำกัด
- การชำระเงินเป็นการ **จำลอง** — ใช้งานจริงต้องเชื่อม payment gateway / escrow (ตอนนี้ผู้ซื้อกด "ชำระ" เองได้)
- ยังไม่มีหน้า Admin ตรวจข้อพิพาท/ยืนยันตัวตน: แก้ `users.Verification_Status` และ `reviews_disputes` ผ่าน phpMyAdmin
- ตั้ง Admin: `UPDATE users SET Role='Admin' WHERE Username='...'`
- ไม่เก็บเลขบัญชีธนาคาร/บัตรประชาชนในเว็บ (ช่อง `users.Bank_Account` ยังมีในตารางแต่ไม่ถูกใช้)
- ขึ้นเว็บจริงควรใช้ HTTPS (cookie เซสชันจะตั้ง `Secure` ให้อัตโนมัติ) และสำรองฐานข้อมูลสม่ำเสมอ
